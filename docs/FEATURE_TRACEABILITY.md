# Feature Traceability

Every shipped feature mapped to the three obligatory North Star dimensions and to a user
outcome. A feature contributing to none of them is not built — this matrix is the check.

**R** = Recency (what changed) · **D** = Depth (how this market works) ·
**A** = Applicability (what I say or ask next)

## Deliberately not built

| Not built | Why | Dimension it would have served |
|---|---|---|
| Infinite scroll | Contradicts finite consumption | none |
| Likes / follower counts | Popularity is not impact | none |
| Streaks and gamification | Manipulative retention | none |
| Sentiment scores | A number without evidence | none |
| Trending-by-volume | Ranks communication, not events | none |
| Article-level feed | Ten reports of one announcement is one item | none |
| Accenture navigation area | Would make one firm the organising principle | none |
| Reserved consulting brief quota | Would displace more important developments | none |
| Engagement metrics in ranking | Would produce the product this replaces | none |

Each of these would have added surface area and served no user outcome. The matrix is
what made that visible.
